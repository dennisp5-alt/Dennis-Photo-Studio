# Dennis Photo Studio v0.1 — Upstream attribution
Experimental Android photo editor built from
https://github.com/artcraft-android/lightcraft-android
at revision c6fac28eb7636cbb06ab078395e3d7e519c2efcf.

This branch is a source snapshot, not a GitHub network fork.
The original upstream licence files, notices, Rust image pipeline,
natural White Balance and presets are preserved.
Custom adaptations: independent application ID, own colour palette,
compact save alerts, streamlined toolbar and Auto Amount (0–100%).

IMPORTANT: app is under development. Upstream Android notes state
HEIC decoding is not yet implemented in the native Rust engine.
No AI plugin is integrated in this release.
